# Guide Utilisateur

Bienvenue dans l'application **Dataviz – Master ACTUARIAT 24/25**.

## Navigation de l'application

- **ACCUEIL** :  
  Dans cette section, un carousel d'images démarre automatiquement. **Veuillez patienter environ 2 secondes** après l'ouverture de l'application pour que le carousel se lance correctement.

- **ANALYSE** :  
  Cette section est divisée en deux sous-onglets :
  - **DATA_CHART** : Affiche des tableaux de données pour l'analyse.
  - **GRAPHICS** : Propose plusieurs questions de visualisation.  
    **Attention pour la Question k (Boxplot animé avec gganimate)** :  
    Lorsque vous sélectionnez cette question, **veuillez patienter environ 5 secondes** afin que le GIF animé se charge complètement.

- **RÉPONSES** :  
  Cette section présente le code source et des explications détaillées sur chaque visualisation.

- **GUIDE UTILISATEUR** :  
  Vous êtes ici ! Ce guide vous fournit toutes les instructions pour une navigation optimale.

## Conseils d'utilisation

- **Temps de chargement** :  
  Certains éléments interactifs (comme le carousel ou le GIF de gganimate) nécessitent un temps de chargement. Laissez quelques secondes au contenu pour qu'il apparaisse correctement avant de passer à une autre action.
  Pour le carousel, lors du clic dans l'application, il se lancera après quelques secondes.

- **Interactivité** :  
  Utilisez les menus déroulants et les boutons pour explorer les différentes questions et visualisations.  
  Par exemple, dans le panneau **GRAPHICS**, sélectionnez la question désirée depuis le menu pour afficher la visualisation correspondante.
  
  Cliquez sur mettre à jour la carte pour pour ajouter le point sur la carte.

- **Navigation intuitive** :  
  Le menu latéral vous permet d'accéder facilement aux différentes sections de l'application. N'hésitez pas à revenir à ce guide si vous avez besoin de rappels sur la navigation.

Bonne exploration !
